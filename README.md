# 心心小岛

一个受《朋友收集 梦想生活》启发的 3D 网页小游戏：在一座小岛上收留可爱的居民，照顾他们的日常、帮他们交朋友、布置他们的小屋。

**在线玩：** https://nkjsy.github.io/rensen/ （手机、电脑浏览器都可以）

## 玩法

- **点小人**：查看心情、饱腹度和当前愿望，可以喂食物、送礼物、摸摸头、介绍朋友。
- **实现愿望**：满足居民的愿望能拿到金币，攒够经验还会升级。
- **交朋友**：居民会自己聊天，关系从「朋友」到「好朋友」再到「最好的朋友」。
- **小卖部**：用金币买食物、装扮和家具。
- **布置房间**：点房子进屋，摆放家具、换墙纸和地板。
- **新居民**：分「基本 / 脸 / 发型 / 身材 / 声音」几页捏人：性别、13 种发型、10 种发色、7 种眼睛、眉毛、鼻子、嘴巴、腮红雀斑、胡子，还能调身高和胖瘦。女生只用女声，男生只用男声。
- **小岛会长大**：每多一位居民（新居民、出生的宝宝、留下来的旅行者），小岛都会自动变大一点，最多住 50 人。住满 8 人时外圈开放并解锁 🌷花田、♨️温泉、💇美发店；之后每住满一圈，外面就会再开一圈新的宅基地和道路。
- **16 种性格**：用四条滑杆（慢吞吞↔急性子、温吞↔直率、内向↔外向、随性↔认真）组合出 4 大类 × 4 小类的性格，会影响走路快慢、爱不爱聊天、说什么话。
- **昼夜循环**：天黑后大家回家睡觉，可以点「睡到天亮」跳过夜晚，每天早上送金币。

### 人生大事（仿《朋友收集 梦想生活》）

- **恋爱**：好感度很高的两个人，有一方会偷偷喜欢上对方（头顶 💘）。点他，选一种表白方式（直球 / 情书 / 搞笑），两人会到喷泉边上演表白小剧场。性格对上了成功率更高，被拒绝也会难过哦。
- **求婚与结婚**：交往一阵子后，有人会想求婚（💍），帮他一把就能在喷泉边举行婚礼。
- **宝宝**：结婚后的夫妻某天早上可能会迎来宝宝：送子鸟会叼着小包裹飞来，包裹轻轻落在爸爸妈妈中间，宝宝就出生了，还可以给宝宝取名字。宝宝会搬进空房子。按真实的人生节奏成长（小岛上 10 天是一年）：婚后至少一年才会有第一个孩子，之后至少隔两年，每个家庭最多 3 个孩子；孩子从婴儿、幼儿、上学一路长到 18 岁成年，个子会一点点长高，说的话也会随年龄变化，婴儿和幼儿会跟在爸爸妈妈身边。
- **吵架与和好**：朋友聊天时偶尔会吵起来（💢）。吵架后两人会互相躲着，不再一起聊天。你可以帮他们和好，但刚吵完很难劝，每天只能劝一次，隔几天再劝更容易成功。两人过几天也可能自己慢慢和好。
- **口头禅与对话**：每个居民都有口头禅，点开会说一句符合心情和近况的话。新居民可以自己设口头禅。
- **梦境**：晚上进入睡着居民的家，可以偷看他在做什么奇怪的梦。
- **小岛新闻**：右上角 📰 记录每天发生的大事，早上出炉新一期。

### 小岛上的地方

- **服装店**：买连衣裙、西装、和服、公主裙、恐龙装、宇航服……在「送礼物」里给居民换上。居民有时也会想穿某件衣服。
- **咖啡店**：买咖啡、奶茶、布丁；也可以请店里的大家喝一杯，增进感情。
- **游乐园**：选两个人一起坐摩天轮，说不定会擦出火花。
- **瞭望台**：爬上去俯瞰整座小岛。
- **海滩**：居民空闲时会去海边、咖啡店、游乐园、瞭望台闲逛；情侣聊完天常常会结伴去约会（💕）。
- **演唱会舞台**：选一位居民、一首歌，或者自己写歌名和歌词、挑曲风（流行 / 摇滚 / 民谣 / 说唱），居民会用自己的声音一字一字唱出来，台下观众会鼓掌。
- **港口**：有时会有旅行者坐船来访，可以请他吃东西换纪念品，或者邀请他住下来。他晚上 8 点就会离开。

- **拉面店**：买拉面、寿司、饺子、咖喱饭（只有这里卖），也可以请店里的大家吃一顿。
- **图书馆**：每位居民每天可以来读一次书，心情变好还能涨成长值。
- **宠物乐园**：点一下，岛上的宠物都会跑来一起玩，宠物和主人都会更开心。
- **运动场**：选两位居民赛跑，急性子跑得更快，赢了有金币。
- **露营地**：傍晚 6 点生火，大家会围着篝火坐；点一下会有人讲故事，大家关系更好。
- **游泳池**：让居民去游几圈，心情变好，不过会饿。

### 更多人生大事

- **生日**：每位居民都有生日（小岛上 10 天是一年）。生日那天去广场给他办派对，大家会一起唱生日歌、吹蜡烛、送礼物。
- **升级奖励**：居民升级后可以挑一个奖励：学一首新歌、换一件新衣服、换口头禅、送你礼物或者金币。
- **三角恋**：表白的时候，可能会有第三个人冲出来说“我也喜欢 TA”，最后由被表白的人来选。
- **分手**：情侣吵架、感情变淡时可能会分手。
- **聊聊天**：居民会问你问题——猜猜他在想什么、他是怎样的人、帮他起外号、记不记得他不爱吃什么。
- **背景音乐**：白天轻快、傍晚柔和、夜晚安静。右上角喇叭按钮可以在「音乐 + 音效 / 只要音效 / 静音」之间切换。

### 更像人森的日常

- **🏢 心心公寓**：底部「公寓」按钮，一栋楼里每扇窗户一个居民，能看到谁在干什么、谁需要帮忙，晚上在家的窗户会亮灯；点窗户直接去找他。
- **🙋 我自己**：在公寓里捏一个你自己住在岛上，居民会和你交朋友、送你礼物、邀请你去家里玩。
- **💬 对话小剧场**：居民聊天时头上会冒出真正的对话；聊得好还会一起去散步、拍合照、跳舞、打雪仗。
- **🎮 更多烦恼和小游戏**：接苹果、翻牌配对、打地鼠、找不同；还有睡不着、想尝没吃过的东西等烦恼。
- **📺 电视新闻**：每天由一位居民当主播，一条条播报小岛大事和奇怪的小新闻。
- **🛒 每日进货**：小卖部每天上架不同的商品，数量有限，还有一样 6 折特价。
- **🌦️ 天气和四季**：春夏秋冬换颜色（秋天红叶、冬天下雪堆雪人），会下雨（大家打伞、躲进咖啡店）、雨后彩虹。
- **🎉 节日**：新年（压岁钱）、情人节（巧克力和心动）、夏日祭（烟花）、万圣节（要糖）、圣诞节（圣诞树和礼物），居民会戴节日帽子。
- **🏠 家庭派对**：居民会请好朋友晚上来家里开派对，点他家就能进去看。
- **💼 职业**：每个居民有工作（拉面师傅、咖啡师、救生员……），工作日白天会去上班，第二天把工资交给你；点资料里的职业标签可以换工作。
- **📷 纪念相册**：婚礼、宝宝出生、生日派对、演唱会时会自动拍纪念照放进相册。
- **🎨 设计工坊**：自己画 16×16 的小图案，可以印在居民衣服上，也能挂在家里当海报。
- **🌟 人生梦想**：每个大人有一个梦想（当歌手、环游世界、尝遍美食、成为运动健将……），资料里能看到进度，实现那天全岛庆祝、自动拍纪念照，过几天会有新梦想。
- **🏫 学校**：6 岁以上的孩子工作日白天去上学，每天出成绩，和同学慢慢变成朋友；18 岁毕业，找到第一份工作。可以让居民当老师。
- **🍳 厨房做菜**：买鸡蛋、米饭、番茄、肉等食材，两两搭配做出蛋包饭、寿喜烧、松饼等 12 道菜；搭配不对会变成黑暗料理。
- **✈️ 出岛旅行**：居民偶尔从港口出发去巴黎、京都、纽约等地旅行两三天，回来带特产，还会寄回一张旅行明信片放进相册。
- **👴 变老和退休**：大人每过一次生日长一岁，50 岁后头发慢慢变白，65 岁退休，退休后喜欢在棋桌下棋、去海边晒太阳。
- **📖 图鉴**：记录收集过的食物、饰品、衣服、家具、鱼、虫子、贝壳，以及小岛发生过的 24 件大事，每类集齐可领 300 金币。
- **👪 族谱**：按辈分显示岛上的家庭：夫妻、恋人和他们的孩子。
- **🎣 钓鱼、🦋 抓虫、🐚 捡贝壳**：点港口钓鱼（浮漂一沉马上收竿），白天点露营地进草地抓虫，点海滩捡贝壳。抓到的都会记进图鉴，稀有的有鲸鱼、鲨鱼、珍珠，偶尔还能捡到装着居民纸条的漂流瓶。
- **🏡 房子外观**：在居民家里点「🏡 外观」，可以换房子样式（经典小屋 / 童话木屋 / 摩登平顶）、屋顶和墙壁颜色，还能加白栅栏小花园。
- **💌 居民来信**：居民会在早上给你写信：感谢你送的礼物、请你来派对、孩子画的画，有时信里附礼物。在「公寓 → 💌 信箱」查看，有新信时公寓按钮上有红点。
- **🗣️ 居民记得你**：你送过的饰品衣服、喂过的食物、帮忙表白和和好、办的派对、一起玩的小游戏，居民都会记住，聊天和写信时会提起。
- **🔗 分享居民**：点小人名片右上角的 🔗，得到一串代码和二维码；朋友在「公寓 → 🔗 导入居民」粘贴，这位居民就搬进朋友的小岛。
- **🎵 背景音乐**：春夏秋冬各有一首曲子，下雨天、新年、情人节、夏日祭、万圣节、圣诞节也有专属音乐。
- **🎯 每日任务、成就和日历**：右上角 🎯 每天有 3 个小任务（送礼、钓鱼、聊天……），完成领金币，全部完成还有神秘礼物；23 个成就；日历里能看到这一周的节日、生日、跳蚤市场和运动会。
- **🔮 占卜屋**：在公寓里带居民去算运势（桃花运、口舌之灾、财运、贪吃运、大吉、小凶），运势会真的影响当天：桃花运更容易表白成功，口舌之灾容易吵架，财运好会分你钱。
- **🎭 话剧**：点舞台选「演话剧」，挑剧本（王子与公主、喷泉谜案、太空大冒险、饭团历险记）和 3 位演员。演员会照剧本演，搞笑性格的人常常忘词、即兴发挥，观众会笑翻。
- **💭 梦境小剧场**：偷看睡着的居民，会看到会动的梦：被大饭团追、在月亮上野餐、下食物雨、和鲸鱼唱歌……
- **🗣️ 居民找你商量人生大事**：要不要表白、要不要换工作、换什么发色、想个新口头禅、周末去哪儿玩，你的回答会真的改变他们的生活。
- **💬 口头禅会传染**：孩子会学爸妈的口头禅，形影不离的好朋友也会越说越像。心情好的居民还会自己写歌。
- **💒 婚礼和蜜月**：求婚成功后可以挑场地（喷泉广场、花田、海滩）和礼服办婚礼，婚礼后两人住到一起，然后去度蜜月。
- **😢 恋爱剧情**：居民会悄悄暗恋别人，几天后鼓起勇气表白；分手的人可能旧情复燃；夫妻吵得太凶会离婚。
- **🛒 居民小摊和跳蚤市场**：每天有居民摆摊卖东西，每周三是跳蚤市场（摊位多、五折）。
- **🏃 运动会**：运动场能让 2～4 位居民赛跑，比赛时狂点「加油」能让你看好的人冲得更快，周六运动会奖品加倍。
- **🎣 季节限定和大小纪录**：每个季节有限定的鱼、虫子和贝壳（夏夜才有萤火虫），每次抓到都有尺寸，刷新纪录会提示。
- **🐾 宠物更活泼**：宠物会自己去散步，偶尔叼回宝物；两只宠物碰到会成为好朋友，一起玩耍。
- **💾 存档**：在公寓里可以下载存档文件或复制存档代码，在别的电脑、浏览器里导入接着玩（网页版和本地版之间也能互通）。

### 更多小乐趣

- **猜拳**：点小人选「猜拳」，三局两胜，赢了拿金币。居民有时也会主动想玩（✊）。
- **拍照模式和相册**：右上角 📷 进入拍照模式，可以拖动换角度、定格画面、加滤镜（暖阳、黑白、复古、梦幻、冷调）、贴贴纸、选拍立得或爱心边框，可以放进相册，长按或右键图片就能存到设备。
- **烟花大会**：每 3 天有一次，晚上 7 点半大家会聚到广场看烟花。
- **会说话**：居民开口时会用浏览器的中文语音念出来。每个人会被分到不同的音色（比如慧慧、康康、瑶瑶；Edge 浏览器里还有晓晓、云希等更自然的语音），音调和语速也各不相同；捏人或换造型时可以自己挑音色、调音高语速并试听。
- **换造型**：点小人选「换造型」，可以重新改名字、发型、衣服、性格、口头禅和声音。

**自动更新**：开着网页版玩的时候，游戏每隔几分钟会检查有没有新版本，有的话会弹出「🎁 小岛有新内容啦」，点「立即更新」会先存档再刷新，进度不会丢。

拖动旋转视角，滚轮 / 双指缩放。左上角的 ⏸ 可以暂停（暂停时能选择继续或重新开始），1× / 2× 切换正常速度和 2 倍速。进度自动保存在浏览器的 localStorage 里。

## 装到手机桌面

用手机浏览器打开 https://nkjsy.github.io/rensen/ ，iPhone 在 Safari 里点「分享 → 添加到主屏幕」，安卓在 Chrome 菜单里点「添加到主屏幕 / 安装应用」。之后就像一个 App 一样从桌面打开，玩过一次后没网也能玩。

## 本地打开

直接双击 `index.html` 用浏览器打开即可。游戏通过 cdnjs 加载 three.js r128，所以需要联网。

如果想用本地服务器：

```bash
python -m http.server 8000
```

然后访问 http://localhost:8000 。

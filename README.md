# 猫猫小岛

心心小岛的猫咪版：一座住满 3D 小猫的小岛。你是岛上唯一的人类（铲屎官），照顾猫咪们的日常，看它们交朋友、谈恋爱、生小猫、慢慢变老。

**在线玩：** https://nkjsy.github.io/cat-island/ （手机、电脑浏览器都可以）

## 玩法

- **点猫咪**：看心情、饱饱、亲密度和愿望，可以喂食、摸摸头、梳毛、送装扮。摸太多会烦，傲娇的猫会哈气。
- **愿望**：晒太阳、钻纸箱、上高处、吃没吃过的鱼、梳毛、抓蝴蝶……
- **亲密度**：每只猫和你都有自己的亲密度，够亲了它会叼礼物给你（树叶、小虫、袜子，偶尔是宝贝）。
- **纸箱**：岛上每天会冒出几个纸箱，猫咪路过就想钻进去，抢不到还会吵架。
- **猫薄荷**：在猫粮店买，或者去猫薄荷田摘。闻了会打滚发疯，然后犯困。
- **捏猫**：先选品种，再调毛色、脸、体型、装扮，四条性格滑杆（慵懒↔好动、温顺↔傲娇、怕生↔黏人、随性↔讲究），还能选嗓音、调喵声高低。
- **猫窝**：家具都是猫用的：猫爬架、猫砂盆、猫抓柱、鱼缸、猫窝、墙上跳台、毛线球……猫咪会自己跳上去趴着、蹲猫砂、看鱼。
- **人生大事**：表白（叼一朵花或送一条鱼）、猫婚礼（领结和头纱）、在纸箱里生下一窝 1–3 只小猫（每家最多 3 窝），小猫会遗传爸妈的毛色，长毛、折耳、重点色是隐性的，三花和玳瑁几乎都是母猫。老猫会慢慢变灰。
- **小岛上的地方**：猫粮店、装扮屋、美容院、猫咖、猫咪学校、大猫爬架、喵喵舞台、渔港、猫公寓等。
- **小游戏**：抓老鼠、接小鱼、猫拳。
- 最多住 20 只猫，存档和心心小岛分开。

## 技术

单个 `index.html`，three.js r128 + GLTFLoader。猫叫是 10 只真猫的录音，背景音乐白天和晚上各一首，都是 CC0（来源见 `audio/CREDITS.md`）。PWA，可以加到手机主屏幕。
